# Prompt recipes

Copy a prompt into your AI assistant, replace the parts in angle brackets, and send it. Each one
points the assistant at `AGENTS.md` and `MEDHA_STYLE.md`, so the result follows the Medha style
and passes the project's checks.

| Recipe | Use it to |
| --- | --- |
| `new-page.md` | Add a workspace, website or auth page |
| `new-component.md` | Turn markup from a theme page into a reusable typed component |
| `connect-api.md` | Replace demo data with data from an API |
| `style-review.md` | Review a change against the Medha style |
